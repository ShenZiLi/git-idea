## 手动验收

1. 运行 `npm run dev` 或 Windows 便携 EXE，打开一个本地测试仓库。
2. 修改文件，在提交区查看差异，暂存并填写提交信息；提交后确认日志和工作区同步更新。
3. 从分支菜单创建、切换、重命名分支，合并测试分支；点击日志记录查看文件差异。
4. 添加测试远程，执行获取、拉取和推送；创建、弹出一个储藏。
5. 制造一个合并冲突，编辑保存、标记解决并继续；另一次冲突尝试中止。
6. 拖动分隔线、切换主题和字号、通过快捷键打开各工具窗口；输入未保存草稿后刷新或切换文件，确认保护行为。

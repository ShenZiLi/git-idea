# IDEA 风格分支菜单

日志左侧分支支持右键、行尾省略号和 Shift+F10 打开菜单。F2 重命名，Delete 打开删除确认；快捷键只在分支行内生效。顶部切换器同样支持右键及这些快捷键。

## 当前分支与其他分支

当前分支菜单按用户第二张参考图组织：新建分支、工作树差异、新工作树、更新、推送、跟踪子菜单、重命名。检出自身、比较自身、合并或变基自身、删除当前分支不出现。

其他本地分支按第一张参考图组织，增加检出、检出并变基、检出并更新、与当前分支比较，以及合并或变基到当前分支等操作。菜单显示实际分支名，右键不会改变日志筛选。

| 操作           | 实际方向                                       |
| -------------- | ---------------------------------------------- |
| 签出并变基到 C | 先检出选中分支 S，再将 S 变基到原 C 的提交     |
| 将 C 变基到 S  | 当前仍为 C，变基 C 到 S                        |
| 将 S 合并到 C  | 当前仍为 C，合并 S 到 C                        |
| 与 C 比较      | C..S 的独有提交与两端文件差异；可交换方向      |
| 与工作树比较   | S 与磁盘内容比较，含已暂存、未暂存及未托管文件 |

变基、合并、推送和删除有明确确认。复合操作失败时会说明是否已经检出；冲突保留在 Git 原生状态，沿用提交面板的继续/中止入口。

## 分支、更新与远程

- 从选中分支新建时可选择是否检出，起点不会默认为当前 HEAD。
- 检出远程分支会创建本地跟踪分支。同名本地分支跟踪其他目标时拒绝直接复用，不丢弃已有提交。
- 当前分支可按 merge、rebase 或 ff-only 更新；上次选择按仓库保存在本机。
- 非当前本地分支只安全快进，不切换工作区；已包含上游时不回退，分叉时提示检出后处理。
- 远程分支的更新只获取该引用；可另选拉取到当前分支并合并/变基。
- 推送固定选中的本地分支，显式选择远程和目标分支，可设置上游。不提供强制覆盖推送。
- 跟踪子菜单可搜索远程分支、更换或取消上游；更改跟踪设置本身不推送。
- 本地删除用安全 `branch -d`。远程删除显示真实服务器 remote/ref，并用期望提交租约保护：服务器分支变化后拒绝删除，要求重新获取、确认。租约用于条件删除，不允许覆盖远程历史。

分支菜单先读取实际上下文。写入前重新核对分支、HEAD 和跟踪设置；过期确认会被拒绝。其他工作树占用的分支不能被更新、删除或重新检出。

## 工作树与比较窗口

新工作树可选择绝对目录、可选新分支和创建后是否打开。目标必须不存在或为空目录，不能位于已有仓库、Git 元数据目录内或作为其父目录。已有分支被占用时须使用新分支，不提供 force。远程源会创建本地跟踪分支，不静默创建分离 HEAD 工作树。

比较窗口有方向标题、交换、刷新、独有提交列表、文件统计/搜索及只读单栏差异。选择一条提交可查看它的消息和文件；“全部分支差异”返回两端聚合。分支历史每批 300 条，最多 5,000 条；文件预览限 2 MB 和合计 20,000 行。二进制、非 UTF-8、子模块或受限链接给出说明。

工作树比较先完成编辑器自动保存；差异窗口只读。文件端点固定提交哈希，磁盘端反映读取时的内容，外部编辑后可刷新。

## 对照与交付记录

依据 [IDEA 分支文档](https://www.jetbrains.com/help/idea/manage-branches.html)、[日志菜单](https://www.jetbrains.com/help/idea/log-tab.html)、[变基方向](https://www.jetbrains.com/help/idea/apply-changes-from-one-branch-to-another.html)及 [Git worktree](https://git-scm.com/docs/git-worktree)、[fetch](https://git-scm.com/docs/git-fetch)、[push](https://git-scm.com/docs/git-push)实现。

本轮覆盖截图的单仓库分支菜单。普通检出保留 Git 的改动保护；不自动 force、stash 或引入 IDEA 专有 Smart Checkout/Shelf。多仓库同步和 IDE 工程上下文恢复不属于本次菜单实现。

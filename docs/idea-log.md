# IDEA 风格 Git 日志中间页

## 范围与布局

以用户提供的 IDEA 日志截图和 [IDEA Log tab 文档](https://www.jetbrains.com/help/idea/log-tab.html)为参照，实现中央提交日志的工具栏、筛选、图谱、列表与导航。左侧分支树和右侧固定提交栏沿用现有布局。

默认显示提交主题、作者、完整本地日期时间，不显示独立表头和哈希列。使用 30px 行高、16px 图谱列间距，中性黑灰选中行；第一条图谱线路使用橄榄色。引用分别标识当前分支、本地分支、远程分支和标签。

## 工具栏

| 入口           | 操作                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------- |
| 文本或哈希     | Enter 或离开输入框应用；支持清除、最近 20 条搜索历史、`.*` 正则、`Cc` 大小写             |
| 分支           | 搜索并多选本地分支、远程分支和标签；可选择 HEAD；旁边 X 清除此类筛选                     |
| 用户           | 按真实作者邮箱多选，支持当前用户；没有邮箱的历史作者按姓名匹配，一次最多选择一位此类作者 |
| 日期           | 全部、今天、近 7 天、近 30 天、自定义起止日；含结束日期当天                              |
| 路径           | 每行一个仓库内相对文件或目录；支持当前编辑文件；路径按字面量解释                         |
| 图选项         | 日期或拓扑排序、第一父项、排除合并、折叠线性提交                                         |
| 播放形索引图标 | 用户主动点击后构建本机 Git 提交图与路径索引，显示等待状态和原生错误                      |
| 刷新           | 保留查询、显示选项、有效选择和当前滚动位置                                               |
| 分叉图标       | 定位当前分支 HEAD，不检出分支                                                            |
| 眼睛           | 即时切换列、表头、详情、引用位置、标签名、长边、时间戳和高亮                             |
| 放大镜         | 输入提交哈希、分支或标签并定位；同时显示可选引用                                         |

同一类多项筛选取并集，不同类别取交集。哈希查询也遵守分支、作者、日期和路径条件。错误查询显示错误和重试入口，不继续展示上一份列表冒充结果。

日期排序和日期筛选使用 Git 的提交时间语义；日期列默认显示作者时间，可在显示菜单改为提交者时间。作者与提交者不同时，作者后显示 `*`，悬停查看提交者信息。

正则采用 [Git 扩展正则](https://git-scm.com/docs/git-log)，不是 IntelliJ 的 Java 正则。索引入口实际执行 `git -c core.commitGraph=true commit-graph write --reachable --changed-paths`；这是 [Git 原生 commit-graph](https://git-scm.com/docs/git-commit-graph)，不等同于 IntelliJ 的专有日志索引。日期筛选需要支持 `--since-as-filter` 的 Git 2.37 或更新版本。

## 图谱与大历史

- 按真实父提交关系绘制合并与分叉；筛选外或分页外的父提交显示短虚线箭头，不连接到无关节点。
- 隐藏长边时只保留短箭头；点击出边可定位真实父提交。键盘也可通过左右键或右键菜单导航父提交。
- 只折叠相邻、单父单子、没有引用的线性内部段。保留分叉、合并、根、HEAD、标签和选中节点。点击折叠段展开，不修改仓库历史。
- 列表采用虚拟滚动，每批 300 条，最多加载 50,000 条。超过上限请缩小筛选范围。
- 定位到当前查询外的提交时会清除筛选并加载目标；目标不在默认分支历史或超过上限时，以目标提交为起点显示历史并给出提示。

## 列与菜单

显示菜单的选项即时生效、按仓库保存在本机。显示表头后可拖动作者、日期、哈希列右侧分隔线调整宽度；窄窗口横向滚动时表头与数据同步。存储不可写时，本次会话仍保留各仓库的视图和搜索历史。

右键先选择目标提交，再提供复制哈希、复制完整消息、创建分支、创建标签、拣选、还原、重置和父提交导航。写入操作复用已有的等待、确认和 Git 执行流程；重置仍需选择模式并确认。合并提交的拣选或还原沿用原生 Git 的限制，当前入口不提供 mainline 选择，Git 拒绝时会显示错误。

详情加载按仓库与提交绑定；加载或失败期间不允许使用上一条提交的详情操作。

## 快捷键

以下快捷键在日志区域获得焦点时生效。

| 快捷键            | 操作                               |
| ----------------- | ---------------------------------- |
| Ctrl+L            | 聚焦文本查询                       |
| Ctrl+F            | 打开哈希/引用定位                  |
| ↑ / ↓             | 上一条 / 下一条                    |
| Home / End        | 已加载结果的第一条 / 最后一条      |
| PageUp / PageDown | 翻页选择                           |
| ← / →             | 第一父提交 / 当前结果中的子提交    |
| Ctrl+C            | 复制选中提交哈希                   |
| Shift+F10         | 打开提交右键菜单                   |
| Enter             | 显示提交详情                       |
| Esc               | 关闭弹层；查询框内撤回未应用的草稿 |

macOS 对应使用 Command；本轮交付和界面预览在 Windows 完成。文件编辑器内的 Ctrl+F / Ctrl+H 仍用于文件查找与替换。

# 提交栏

## 文件列表与勾选

- 已托管文件集中显示在“更改”分组，一行对应一个文件，显示文件名和所属目录。新增为绿色、修改为蓝色、未托管为红色，冲突使用红色叹号。
- 勾选对应真实 Git 暂存状态。取消勾选撤销该文件的暂存；不会删除磁盘文件。
- 暂存区与工作区都有改动的文件显示“部分暂存”和横线复选框。查看文件默认打开工作区差异，行末眼睛按钮单独打开已暂存差异。取消该文件的勾选会取消暂存；已有部分暂存不会因刷新或打开文件而被覆盖。
- 分组复选框支持全部暂存、全部取消及混合状态。混合状态下勾选分组会暂存剩余工作区内容，包括部分暂存文件的剩余内容；取消全部暂存也可通过更多菜单操作。冲突文件不参与批量勾选。
- 未托管文件默认只显示数量和“浏览”入口。浏览窗口支持按名称/路径筛选、每页 100 个文件、单文件暂存和本页暂存。暂存后文件移入“更改”分组，已排除文件不列入未托管文件。
- 已托管列表初始展示 100 个文件，按需显示更多。展开/收起操作不会自动渲染全部未托管文件。
- 批量暂存和取消暂存通过 Git 的零字节分隔路径输入传递文件列表，避免大量文件超过 Windows 进程参数长度限制。大选择范围的格式过滤会读取索引后按路径筛选，继续保留非选中文件的暂存内容。

## 工具栏

- 刷新同步本地 Git 状态。
- 回滚丢弃选中文件的未暂存内容，保留已暂存内容；删除未托管文件前会明确提示并要求确认。
- 暂存切换作用于当前选中文件；储藏复用现有 Git 储藏对话框，包含暂存区、工作区和未托管文件。
- 眼睛按钮查看选中文件的差异。定位按钮在更改列表中找到编辑器当前文件，未托管文件则打开对应浏览页。
- 更多菜单提供全部暂存、全部取消暂存、浏览未托管文件和设置。提交栏固定显示，可拖动分隔线调整宽度；Ctrl+K 聚焦提交信息。

## 提交消息

- 消息区随面板高度伸缩，保留 Ctrl+Enter 提交快捷键。
- 勾选“修订”会载入上次提交消息；取消勾选会恢复进入修订前的草稿。正在合并、变基等操作期间禁用修订，继续/中止操作保留独立入口。
- “上次提交”菜单可复用上次消息或进入修订；时钟按钮打开消息历史。
- 成功提交的消息按仓库保存在本机应用存储，最多 30 条；历史窗口还合并当前日志中的消息。提交失败时保留输入内容，消息历史存储失败不会影响 Git 提交。
- 提交仅包含暂存内容，底部显示待提交文件数。空消息、未选择文件及未解决冲突会阻止提交；纯格式差异继续使用既有过滤规则。
- “提交并推送”需要配置远程、位于本地分支并经过确认。推送失败不重复创建提交。普通提交不触发推送。

## 浮层与主题

菜单和浏览/历史窗口挂载到页面顶层，避免玻璃面板的背景滤镜和裁切影响位置。沿用现有亮暗配色、焦点样式、键盘操作及减少动态效果规则。

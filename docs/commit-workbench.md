# 提交工作台（方案 A）

设计先于实现。已确认设计见 [详细设计](superpowers/specs/2026-10-17-commit-workbench-design.md)，任务记录见 [实施计划](superpowers/plans/2026-10-18-commit-workbench.md)。

## 提交与更改列表

右侧提交栏固定显示，包含「提交」「搁置」「恢复记录」。切页保留提交消息与修订状态。

- **勾选就是 Git 暂存**。外部 Git 的部分暂存仍然有效，复选框显示混合状态。
- **选中是操作范围**。支持 Ctrl 多选、Shift 范围选择、分组选择和右键操作；搜索隐藏的已选文件会显示数量。
- **列表用于组织文件**。内置「更改」不可删除，可创建、编辑、删除普通列表并设为活动列表。新出现的已托管更改进入活动列表，重命名沿用归属。
- 提交范围可选全部已暂存、指定列表、所选文件。确认窗列出实际路径，并提示哪些文件还有未暂存内容。提交读取索引中的版本，其他文件的暂存内容保留。
- 每个列表和修订分别保存消息草稿；消息历史按仓库隔离。提交前先完成编辑器自动保存。
- 支持平铺、目录、模块分组；模块识别真实项目标记，也可手动配置根目录。未托管和已忽略文件单独浏览，默认每批 100 项。

文件或列表右键提供适用的暂存、取消暂存、显示差异、独立差异窗口、回滚、搁置、移动列表、补丁导出和文件删除。冲突、未托管、忽略项的操作按状态限制。

## 独立搁置 Shelf

Shelf 与原生 Git stash 分开保存。每条记录保存基线、原暂存版本、工作区原始字节、文件模式、重命名两端、完整二进制补丁和摘要。

1. 选择已托管更改，点击「搁置更改」或使用右键菜单。
2. 输入名称，选择存档后移除，或仅复制备份。没有首个提交时仅支持复制。
3. 在「搁置」页选择记录及文件，预览工作区或暂存差异。
4. 恢复时选择目标列表，可复制到工作区并保留记录，也可恢复原暂存状态。

恢复会先预检整个所选批次。目标被外部编辑、同名未托管文件、冲突或补丁不能应用时拒绝覆盖，原存档保留。可另存归档内容后手工合并。没有自动三方合并或忽略失败后强行应用。

删除搁置先进入「最近删除」，可恢复；明确确认永久删除后才清除对应 UUID 目录。已应用记录独立展示，部分应用按文件标记。

## 补丁、回收和恢复

- 创建或复制「HEAD → 工作区最终内容」或「HEAD → 暂存区」补丁。Shelf 也可导出所选文件的补丁，包含二进制内容。导出不暂存、不提交、不回滚。
- 桌面端使用系统保存窗口；取消保存不显示失败。剪贴板上限 8 MB，大补丁导出到文件。浏览器仅支持受限大小的补丁下载。
- 文件删除先保存内容和索引备份，Windows 再送入系统回收站，不自动执行 Git 删除暂存。浏览器保留应用内备份后移除磁盘文件。
- 「恢复记录」展示中断操作和历史回收/回滚备份。可预览并另存前后版本，也可在指纹仍匹配时完成操作或恢复操作前内容。
- 提交已创建但索引同步失败时展示真实提交标识，暂停 Git 写入。恢复只同步索引，不再次创建提交，也不会自动撤销提交。
- 外部 Git 或编辑器产生后续改动时停止自动恢复，保留材料。不会自动删除其他进程的锁。

资料位于当前 worktree 的 Git 管理目录下 `git-idea/`，不会进入项目跟踪文件。元数据带 revision，写操作共享仓库队列及工作台锁。跨文件操作使用持久日志和备份恢复，不承诺跨文件原子落盘。

## 原生 Git 储藏

底部「储藏」页继续使用 Git stash。预览包含暂存、工作区及未托管文件。操作以对象标识重新定位，序号移动不会选错记录。应用成功而后续删除失败时明确提示已应用，避免重复操作。

## 快捷键与限制

| 快捷键           | 操作                   |
| ---------------- | ---------------------- |
| Ctrl+K           | 聚焦提交消息           |
| Ctrl+Enter       | 预览并确认当前范围提交 |
| Ctrl+D           | 所选文件差异           |
| Ctrl+Alt+Z       | 回滚确认               |
| Ctrl+Alt+P / M   | 目录 / 模块分组        |
| F2               | 编辑列表或搁置名称     |
| Delete           | 删除确认               |
| Shift+F10 / Menu | 上下文菜单             |

树快捷键仅在对应树内生效，不接管编辑器和输入框。独立差异窗口仅可查找（Ctrl+F）、复制及关闭，不能写入文件或修改设置。

原始归档单文件上限 64 MB、单记录 256 MB，文本预览上限 2 MB。通用归档和范围提交拒绝冲突、链接、子模块、稀疏检出及进行中的合并/变基等操作。纯行尾空白和换行格式仍遵循既有提交过滤规则，缩进可提交。

本轮按已批准范围实现文件级列表；不包含 UML、文件内代码块归属、外来补丁导入和多仓库统一操作。Windows 为交付平台，macOS/Linux 原生验收尚未进行。

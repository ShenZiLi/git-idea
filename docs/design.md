# Git IDEA 设计与验收

## 目标与方案

跨平台桌面 Git 客户端，采用已确认的 Electron + React + TypeScript。布局严格参照用户提供的 IDEA 截图：顶部项目与分支工具栏、左侧项目树、中部文件/差异编辑器、右侧提交工具窗口、底部分支树/提交图谱/详情以及状态栏。默认中文与 Darcula 深色主题；面板可调节，保留键盘操作。

交付顺序：用户确认先实现 Windows 端。本阶段验收 Windows 生产窗口和便携 EXE，macOS/Linux 的原生适配与验收后续进行。

## 代码边界

- `electron/git.ts`：通过参数数组执行本机 Git，解析真实仓库，不拼接 shell 命令。
- `electron/main.ts` / `preload.ts`：沙箱窗口、窄接口 IPC、原生文件夹选择和偏好持久化。
- `electron/api.ts`：桌面和仅绑定本机的开发服务共用的请求分发。
- `shared/types.ts`：仓库、变更、提交、分支、差异等接口。
- `src/components/`：项目树、编辑器、提交窗口、日志、分支与对话框。
- `tests/`：在临时真实仓库中验证变更、提交、分支、远程和储藏流程。

## 功能验收

1. 打开、最近仓库、初始化、克隆；空仓库和未打开仓库有正确引导。
2. 显示实际文件树和内容、工作区/索引状态；支持逐文件和全部暂存/取消暂存。
3. 提交、修订上次提交，提交前校验；显示 Git 返回的失败信息。
4. 本地/远程分支及标签；创建、切换、改名、安全删除、合并、变基、拣选、还原提交。
5. 提交图谱、搜索与筛选、提交详情、文件变更、统一/并排差异；正确处理初次提交、删除、重命名和二进制。
6. 获取、拉取、推送、远程管理；支持 Git 原有 SSH/凭证机制，显示进度和结果。
7. 储藏列表、新建、应用、弹出、删除；冲突可查看与标记解决，继续或中止正在进行的操作。
8. 项目面板/提交面板/日志面板可隐藏及调整尺寸；支持快捷键、主题与字体设置和命令日志。
9. Windows 桌面运行与打包验证；提供 Windows/macOS/Linux 打包配置和 CI。其他系统的原生运行必须在对应系统验证。

## 数据和异常

Git 是唯一仓库事实来源，每次操作后重新查询。原生层只允许显式白名单操作，禁用 Node 集成、启用上下文隔离和沙箱。文件读取限定仓库范围并处理符号链接；文本大小设限。破坏性操作显示实际目标和确认，网络写操作只能由用户在界面主动触发。项目开发的每批改动都提交本地 Git。

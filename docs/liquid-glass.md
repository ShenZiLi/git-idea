# 液态玻璃外观

## 范围与来源

按用户指定的 `ui-ux-pro-max` 技能实现，项目仍为 Electron + React + TypeScript 的 Windows 桌面 Git 客户端。

技能风格库匹配到有效的 `liquid-glass` 记录：材质主要用于导航、控件和浮层，内容需要独立且清晰，并尊重减少透明度及减少动态效果偏好。两次完整设计系统检索未获得适用于本项目的完整桌面方案，因此布局和配色采用既有工作区结构及技能内的通用可读性原则；没有保存不适用的检索结果。

Windows 上通过 CSS 半透明表面、背景模糊、高光边缘和分层阴影实现该风格，没有增加依赖。背景为静态环境光，文件编辑区、差异和日志正文使用实底。字体仍由用户设置决定，不加载网络字体。

## 主题与材质

- 暗色：深黑背景（`#090909`）、中性黑灰玻璃与白色高光；阅读区为 `#121212`，浮层为高不透明度黑灰，选中背景也使用中性灰。蓝色保留于按钮、焦点与操作图标。亮色：雾蓝背景、乳白玻璃与深色文字。
- 工作区保留 IDEA 的五区布局。工具轨和面板使用圆角、细分隔与内侧高光，代码、Git 状态及选中标记保持清楚。
- 菜单、弹窗、通知使用高不透明度的玻璃层，模糊为 22px，暗色饱和度为 100%、亮色为 145%；不对模糊和面板尺寸做动画。暗色预览卡片与桌面启动背景同步使用中性黑灰。
- 设置顶部提供「亮色模式」「暗色模式」原生单选预览卡片。选中状态同时使用勾选、边框和原生 checked 语义；方向键可切换，选择后立即应用并自动保存。设置页不再提供保存或取消按钮，通过标题栏关闭。
- 主题切换继续抑制整页颜色过渡；键盘打开浮层和减少动态效果模式保持即时反馈。
- 减少透明度、提高对比度及强制颜色模式使用实底并关闭背景模糊；不支持 backdrop-filter 时使用实底。保留原生强制颜色适配。
- 不在包含全屏菜单遮罩的祖先上增加背景滤镜，以保留遮罩的视口范围。

| 前景 / 背景           | 声明颜色              | 计算对比度 |
| --------------------- | --------------------- | ---------- |
| 正文 / 阅读区         | `#ededed` / `#121212` | 16.00:1    |
| 次要文字 / 选中背景   | `#bdbdbd` / `#303030` | 7.02:1     |
| 置灰文字 / 选中背景   | `#a7a7a7` / `#303030` | 5.49:1     |

以上按 sRGB 声明颜色计算；透明玻璃实际显示还取决于底层内容，表格不代表整页对比度认证。

以下为墨蓝色液态玻璃初版的历史查看记录，其中暗色数值不代表当前深黑配色。当前设置已改为即时生效与自动保存，不再显示保存按钮。

本轮通过浏览器查看亮暗外观、保存并重新载入模式、方向键单选、焦点描边、菜单遮罩范围、右侧提交菜单原点、文件阅读区域及减少动态效果状态。约 1001×680 的 CSS 视口中，设置内容可以滚动到保存按钮；强制颜色模式下弹窗背景为实色，背景滤镜为 none。上述查看过程没有页面运行错误。

未验证：Windows 系统「减少透明度」偏好的实际联动、实体触屏和屏幕阅读器。移动端及 macOS/Linux 原生界面不在本阶段 Windows 交付范围内。本轮没有运行整套自动化测试。
